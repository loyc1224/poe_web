# 💎 PoE2 地面掉落物即時 OCR 查價工具 (Drop/Screen Price Checker)

專為 Path of Exile 2 地面掉落標籤（如 `20x 點金石`、`4x 改善之兆`、`神聖石`）設計的 **自動螢幕框選與 OCR 即時查價小工具**！

---

## 🌟 工具特色

1. **🎯 自由螢幕選區 (Region Selector)**：
   - 點擊「選取螢幕掃描範圍」按鈕，滑鼠可以在螢幕上自由框選任意區域（例如地上的掉落物區域或畫面中央）。
2. **⚡ 專用圖像前處理與雙語 OCR (Chi_Tra + Eng)**：
   - 使用 OpenCV 做 2x 圖像放大、灰階化、CLAHE 對比拉伸與 Otsu 自適應二值化，有效克服遊戲地面的黑/橘底色與光影干擾。
   - 自動解析掉落數量前綴（例如 `20x 點金石` -> 數量 `20`，品名 `點金石`）。
3. **📋 即時輸出文字區 (Real-time Text Log Output)**：
   - 控制主介面下方設有**實時日誌與價格輸出區**，清清楚楚顯示每一秒辨識到的物品、數量、單價與總價！
4. **💰 置頂懸浮價格標籤 (Floating Price Overlay)**：
   - 在框選區域邊緣會跳出亮眼的透明懸浮標籤，即使遊戲全螢幕/無邊框，也能一眼看到目前地面物品的總估價！
5. **🔍 模糊匹配 (Fuzzy Matching)**：
   - 內建中英文對照與模糊比對算法，即使 OCR 辨識字體有些許偏差，也能準確找到對應價格。

## 🚀 啟動方式

### 方法一：雙擊批次檔（最簡單）
直接點擊 `c:\code\poe_web\啟動PoE2地面即時OCR查價工具.bat`。

### 方法二：Powershell / Terminal
```powershell
cd c:\code\poe_web
python -m web.drop_checker.gui_overlay
```

---

## 📖 使用步驟

1. 啟動工具後，點擊 **「🎯 選取螢幕掃描範圍」**。
2. 畫面會出現半透明遮罩，用滑鼠在遊戲畫面的掉落物區域（如地上 `20x 點金石` 周圍）**拉出一個紅色方框**。
3. 點擊 **「▶ 開始自動掃描」**，工具就會每 0.8 秒自動擷取該區域並辨識。
4. 下方的**「即時輸出文字區」**與螢幕上的**「懸浮價格標籤」**會即時更新估價結果！
