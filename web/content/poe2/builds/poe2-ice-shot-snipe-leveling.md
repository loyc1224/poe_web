## 優缺點

**優點**

- 清圖順手：閃電箭前期清怪很平滑
- 打王爆發高：31 等後可用凍結 + 狙擊打出一波帶走
- 昇華依賴低：劇情通關不必綁定特定昇華

**缺點**

- 31 等轉型時屬性很緊，需要預留寶石與裝備詞綴
- 狙擊需要抓節奏，提早或太晚放都會掉傷害
- 凍結窗有冷卻空檔，若一波沒帶走要等待下一輪

## 等級流程

## 1-30 等（轉型前）

### 清怪邏輯

- 主清圖用閃電箭
- 單體先鋪引雷導體，再用閃電箭觸發

### 打王循環（轉型前）

1. 引雷導體疊到對應數量
2. 寒霜爆維持曝露
3. 感電箭（可選）
4. 閃電箭持續輸出到導體消失
5. 彈幕快速補導體，重複上面流程

### 重要提醒

- 連鎖會提升閃電箭可觸發導體的數量
- 寒霜爆有等級壓制，若已無法對當前怪物套曝露就應移除

---

## 31 等轉冰霜射擊

### 轉型前要先準備

- 7/8 等技能寶石：給冰凍印記
- 7/8 等技能寶石：給冰凍齊射
- Spirit Gem：拿冰霜之捷
- Act2 拿到的 Lesser Jeweller's Orb：優先留給狙擊 / 冰霜射擊

### 31 等變體重點（Level 31 Swap）

- 屬性需求參考：力量 20、敏捷 15、智慧 50
- 武器里程碑：33 等改用邪教徒弓，45 等改用火砲弓
- 武器組分配：
	- 武器組 1：冰霜射擊 + 狙擊（主輸出）
	- 武器組 2：冰凍印記（吃印記相關天賦）
- 若狙擊節奏不穩，可先把「機會之窗」改成元素專注，先求穩定輸出

### 31 等推薦技能串法（中文）

| 技能 | 建議輔助 |
|---|---|
| 冰霜射擊 | 元素武裝、疾速攻擊、冰霜之咬 |
| 狙擊 | 元素武裝、集中效應、機會之窗（不熟可改元素專注） |
| 冰凍齊射 | 集中效應、冰霜之咬、急凍 |
| 冰凍印記（武器組 2） | 永恆印記、延長持續時間 |
| 脫逃射擊 | 疾速攻擊 |
| 冰霜之捷 | 元素武裝、擴大範圍、元素專注 |
| 彈幕 | 疾速施法 |
| 戰鬥狂怒 | 視插槽補上 |

### 31+ 打王循環

1. 先上冰凍印記
2. 用冰凍齊射 + 冰霜射擊先凍王
3. 彈幕後接狙擊做一波爆發
4. 若未擊殺，等下一個凍結窗再重複

### 41 等補強

- 可加入龍捲射擊（高血稀有怪 / 王）
- 建議龍捲射擊 x2 起手，再接彈幕 + 冰霜射擊 / 狙擊

## 58 等續文（Campaign End 變體）

### 58 等變體重點

- 屬性需求參考：力量 25、敏捷 30、智慧 55
- 武器重點：45 等後以火砲弓為主，優先做出高傷弓身
- 第一顆 T5 輔助重點：優先拿「充能印記」
- 拿到充能印記後，武器組 2 的天賦優先補：
	- Frazzled
	- The Noble Wolf
	- Unbound Forces
- 目的：放大感電強度，提升單體爆發（原作者測試約可放大一大段王傷）

### 58 等推薦技能串法（中文）

| 技能 | 建議輔助 |
|---|---|
| 冰霜射擊 | 元素武裝 III、疾速攻擊、冰霜之咬、豪賭射擊 |
| 狙擊 | 元素武裝 III、集中效應、機會之窗、元素專注 |
| 冰凍齊射 | 集中效應、冰霜之咬、急凍 |
| 冰凍印記（武器組 2） | 永恆印記、延長持續時間、充能印記 |
| 冰霜之捷 | 元素武裝、擴大範圍、元素專注 |
| 彈幕 | 疾速施法 II |
| 風魔舞者 | 依插槽情況選配 |
| 龍捲射擊 | 提高上限、延長持續時間、耐久 |

### 58 等操作節奏

1. 清圖：冰霜射擊為主，冰凍印記維持增傷節奏
2. 精英 / 王：龍捲射擊暖場後，冰凍齊射凍結，再彈幕接狙擊
3. 狙擊時機：目標已凍結時出手最穩定
4. 記得把狙擊上的元素武裝升到 III，凍結 + 感電條件下收益很高

### 插槽不足時的取捨

- 58 等常遇到技能欄位不夠，需暫時放棄一招：
	- 龍捲射擊
	- 風魔舞者
	- 脫逃射擊
- 原作者在進地圖後常先拿掉脫逃射擊，改留防禦或王戰技能

## 技能與輔助優先概念

## Act1（前期）

- 技能方向：引雷導體、閃電箭、脫逃射擊、閃電之捷
- 輔助優先概念：元素武裝、疾速攻擊、集中效應

## Act2（中期）

- 補上連鎖 II（清怪）與元素武裝 II（單體）
- 視情況在 Chain 與單體輔助間切換

## 31+（轉型後）

- 主體改為冰霜射擊 / 狙擊組合
- 冰凍印記維持增傷窗
- 冰凍齊射協助凍結與連段

## 58 等（劇情尾）

- 冰霜射擊與狙擊都優先升高階輔助
- 充能印記 + 武器組 2 感電天賦，作為王戰爆發核心
- 視插槽在龍捲射擊 / 風魔舞者 / 脫逃射擊間做取捨

## 昇華建議

- 只想快速過劇情：可不急著昇華
- 若要昇華：常見選 Deadeye
- 實戰上，特定移速或投射節奏天賦可能影響狙擊手感，請依自己節奏調整

## 商店英文正則（Vendor Regex）

> 依你需求保留英文，不翻成中文。

```text
bow|mov|[egdl] da.* to a
```

### 用法

- 直接貼進遊戲商店搜尋框
- 以 `|` 代表 OR（任一條件命中即可）
- 可再追加你自己的關鍵字，例如：

```text
bow|mov|[egdl] da.* to a|attack speed|quiver
```
