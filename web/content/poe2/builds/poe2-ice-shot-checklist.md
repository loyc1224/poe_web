# 【POE2】冰霜射擊狙擊遊俠｜實測優化拓荒檢查表

- 實測後比原始教學更穩的版本：核心是弓每 5 級檢查、提早穿精魂胸甲開雙捷、31 級正式切冰霜射擊。

## 核心結論

這套拓荒的控制點不在天賦，而在三件事：

1. 弓要持續更新，至少在 16、26、31 級各重檢一次。
2. 有條件就提早穿高精魂胸甲，先把冰冷之捷與閃電之捷常駐起來。
3. 31 級再切冰霜射擊，王戰靠逃脫之矢疊冰後接彈幕與狙擊收頭。

如果是第二隻角色、有交易資源，最省事的做法是直接穿晨曦之擁朝聖者法衣：需求等級 1，提供 +100 精魂，可以很早開雙捷，後面還能再加幻影射手。

### 最簡單的換弓規則

- 新弓總 DPS 高 20% 以上就直接換。
- 同傷害下優先選攻速快的。
- 冰霜射擊與逃脫之矢都吃弓的攻擊傷害，所以弓比其他裝備重要很多。
- 每升約 5 級回城看一次商店。
- 16、26、31 級是一定要重檢弓的節點。
- 通貨優先花在弓，防具只要生命、抗性、移速與精魂達標即可。

一句話濃縮就是：精魂胸甲提早開雙捷，鞋子拿移速，戒指手套補點傷，箭袋拿投射物等級，弓每 5 級檢查且至少在 16 / 26 / 31 級各換一次。

## 每個技能的獨立串法

## 1. 逃脫之矢：核心冰凍技能

完整串法：逃脫之矢 - 冰冷同調 - 冰凍 - 深度冰凍

用途：

- 被怪包圍時向後跳出怪群。
- 對原位置周圍敵人快速累積冰凍。
- 製造寒冰碎片，補上後續爆炸傷害。
- 王放大招時可以同時閃招與疊冰。

連線不足時的優先順序：

- 二連：逃脫之矢 + 冰冷同調
- 三連：逃脫之矢 + 冰冷同調 + 冰凍
- 四連：逃脫之矢 + 冰冷同調 + 冰凍 + 深度冰凍

如果實戰已經很容易冰住目標，可以把深度冰凍換成偏傷害或範圍的輔助。

## 2. 閃電箭：31 級前過渡清圖

完整串法：閃電箭 - 散射 / 連鎖 - 閃電同調 / 元素武裝 - 攻擊速度

用途：

- 第一章到第二章前半的主要清圖技能。
- 取得精魂後可配合閃電之捷。
- 不需要特地為它重置天賦，只要撐住到 31 級即可。

## 3. 冰霜射擊：31 級正式主技能

清圖串法：冰霜射擊 - 連鎖 I - 霜咬 I - 攻擊速度

清圖流程：

1. 先用逃脫之矢跳進或跳出怪群。
2. 怪物被冰緩或冰凍，地面留下寒冰碎片。
3. 冰霜射擊靠連鎖收掉第一波。
4. 冰冷之捷與寒冰碎片補尾刀。

打王替換：冰霜射擊 - 霜咬 I - 遠程射擊 I - 元素武裝 II

如果當下沒有元素武裝 II，就先保留攻擊速度，先確保手感與站位穩定。

## 4. 狙擊：王戰主爆發

完整串法：狙擊 - 時機之窗 - 沙漏 - 遠程射擊 I

功能：

- 時機之窗放大完美蓄力時機的收益。
- 沙漏提高單發傷害，但會換來輸出空檔。
- 遠程射擊適合安全距離打王。

重點不是站樁硬拉滿，而是先把王冰住，再把蓄力時間放在安全窗口裡。

## 5. 彈幕：把下一個弓技能重複施放

建議串法：彈幕 - 效率 - 預謀類增傷輔助

兩種主要用法：

- 彈幕 -> 冰霜射擊：清圖或補單體都很順。
- 彈幕 -> 狙擊：王戰爆發最高。

按完彈幕後不要誤按逃脫之矢，否則容易把重複效果消耗掉。

## 幻影射手配置

### 方案 A：幻影射手 + 狙擊

- 用途：第二章王與高血量稀有怪。
- 你自己負責逃脫之矢、走位與冰凍。
- 幻影射手幫忙補狙擊傷害。

### 方案 B：幻影射手 + 逃脫之矢

- 用途：清圖更舒服，保命更穩。
- 自動補冰緩、冰凍與寒冰碎片覆蓋。
- 你自己可以專心用冰霜射擊清圖。

選擇方式：

- 清圖容易被包圍：選逃脫之矢配置。
- 第二章王傷害不夠：選狙擊配置。
- 王技能很難閃：改逃脫之矢配置，優先保命。
- 王能穩定被冰住：狙擊配置收益最高。

## 雙捷配置

### 冰冷之捷

- 冰凍怪物被擊殺後能連鎖爆炸。
- 是 31 級冰霜射擊清圖的核心之一。

### 閃電之捷

- 第一章後半配合閃電箭很順。
- 31 級後如果弓上仍有閃電點傷，清圖依然有價值。

精魂不足時的優先順序：

1. 第一章後半先開閃電之捷。
2. 31 級切冰霜射擊後，優先維持冰冷之捷 + 閃電之捷。
3. 第二章王缺單體時，暫時關掉較弱的一捷，換幻影射手 + 狙擊。
4. 清圖容易死時，優先保留冰冷之捷，再改幻影射手 + 逃脫之矢。

## 第二章王實戰流程

1. 逃脫之矢躲技能，同時對王累積冰凍。
2. 冰霜射擊持續輸出並利用寒冰碎片補傷。
3. 再次用逃脫之矢疊冰並調整站位。
4. 王快被冰住時先開彈幕。
5. 王凍結後完整蓄滿狙擊，在完美時機放箭。
6. 狙擊空檔用冰霜射擊補傷。
7. 王解凍後立刻用逃脫之矢撤離，重新開始循環。

口訣：逃脫疊冰 -> 冰霜射擊補傷 -> 王被冰住 -> 彈幕 -> 完美狙擊 -> 冰霜射擊補傷 -> 逃脫離場。

### 第二章王打不動時先檢查什麼

- 第一件事不是改天賦，是先換高傷弓。
- 箭袋改成高點傷或投射物技能等級。
- 冰抗、生命與移速不能掉太多。
- 傷害不夠時先關閃電之捷，保留冰冷之捷與幻影射手。
- 冰霜射擊打王時可拔連鎖，換單體傷害輔助。

## 一句話版拓荒思路

先靠閃電箭撐到 31，過程中把弓當成唯一優先投資目標；有精魂胸甲就提早開雙捷；31 級再換冰霜射擊，王戰靠逃脫之矢冰住後接彈幕與狙擊，不要站樁硬射。
