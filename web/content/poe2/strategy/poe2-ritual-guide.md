# 【PoE2】祭祀實戰攻略：祭壇處理、怪物控場與獎勵取捨

- 本文整理 PoE2 祭祀內容的通用處理流程，重點放在祭祀圈、怪物復活、獎勵選擇與戰鬥中的資訊判讀。
- 截圖案例可見角色在狹窄道路與大型怪物群附近作戰；祭祀時不要只盯著掉落物，應先確認祭祀圈範圍、剩餘怪物與撤退路線。
- 不同版本、地圖詞綴與角色流派可能改變祭祀獎勵和怪物配置，實際數值以遊戲內顯示為準。

## 一、祭祀要做什麼？

祭祀的核心流程可以簡化成：

1. 在地圖中找到祭祀祭壇或祭祀圈。
2. 進入範圍並啟動祭祀事件。
3. 在限定區域內擊敗出現或復活的怪物。
4. 依完成度取得祭祀點數或可兌換的獎勵。
5. 檢查獎勵清單，選擇要立即領取、保留到之後，或重新排列的物品。

祭祀不是單純的清怪點。它會把戰鬥、走位和獎勵管理綁在一起；如果只追著高價物品移動，很容易在怪物尚未清完時被包圍。

## 二、進入祭祀前的準備

### 1. 先看地形

啟動前先用一秒確認以下三件事：

- **退路**：祭祀圈外是否有已清出的空間，能讓角色脫離近戰包圍。
- **障礙物**：牆角、門口、橋面和高低差可能卡住角色，也可能讓投射物或召喚物失去輸出位置。
- **怪物分布**：大型怪、快速近戰怪與遠程怪通常比普通小怪更值得優先處理。

截圖中的戰鬥區域有明顯的道路、牆體與大量屍體。這類場景建議從已清過的一側開始啟動，避免把角色放在怪物、牆壁和地圖邊界的三重夾角。

### 2. 確認資源狀態

啟動前確認：

- 生命、能量護盾或護甲相關防禦在可接受狀態。
- 主要技能、位移技能與保命技能已經冷卻完成。
- 藥劑有足夠次數，並且沒有被上一場戰鬥的異常狀態拖住。
- 召喚物、圖騰或其他需要預先部署的戰力已就位。

不要為了搶一個祭祀點數，在位移技能或防禦技能尚未準備好時強行開戰。

## 三、祭祀圈的推薦處理順序

### 步驟 1：啟動後先清出活動空間

事件開始後，第一目標不是撿物品，而是讓角色周圍留出移動空間。優先清理貼身怪物，避免被多隻近戰怪同時卡位。

### 步驟 2：先處理高威脅目標

一般建議順序如下：

1. 會快速接近、擊暈、冰凍或施加高傷害異常的怪物。
2. 具有範圍技能、遠程投射物或持續地面效果的怪物。
3. 大型稀有怪與高生命怪物。
4. 剩餘普通怪物。

實際順序仍要依流派調整。能穩定風箏的角色可以先處理遠程怪；近戰角色則應先打開退路，再處理會限制移動的敵人。

### 步驟 3：沿著圈邊移動，不要盲目穿越中心

祭祀戰鬥中，沿圈邊繞行通常比站在中心安全：

- 可以看見更多怪物的攻擊前搖。
- 方便回到已清出的區域。
- 能降低同時承受多個方向傷害的機會。
- 便於把怪物拉成一條線，讓穿透、扇形或範圍技能發揮作用。

如果必須穿越中心，先使用位移、護盾或其他短時間防禦手段，不要在怪物密集時徒步硬穿。

### 步驟 4：清完再拾取

祭祀圈內的物品、地面特效和怪物名稱可能互相遮擋。戰鬥中只撿會立刻影響生存的藥劑或必要資源；其餘物品等事件結束後再統一檢查。

聊天視窗會遮住左側戰鬥區與地圖資訊。若要閱讀或輸入訊息，應先離開祭祀圈或確認附近已清空；在事件進行中開啟聊天，容易錯過敵人接近與生命下降。

## 五、獎勵選擇原則

祭祀獎勵不應只看單件物品的表面價格，建議按以下順序判斷：

### 優先保留

- 能直接補足目前流派缺口的裝備或技能資源。
- 高價值通貨、稀有兌換物或角色當前急需的製作材料。
- 需要累積多次才能兌換、但後續有明確用途的獎勵。

### 可以延後

- 價值普通、但不急著使用的裝備。
- 等級不足、需要之後再判斷的物品。
- 占用選項但短期無法提升角色的獎勵。

### 建議放棄或重新排列

- 與流派完全無關、且市場需求低的普通裝備。
- 目前角色無法使用，也沒有明確交易價值的物品。
- 為了拿取而需要重新進入高風險位置的低價獎勵。

實戰時先確保角色安全，再處理獎勵清單。不要因為剩餘時間或獎勵即將消失，就回頭穿越尚未清理的怪物群。

## 六、不同流派的處理差異

| 流派類型 | 祭祀處理重點 |
| --- | --- |
| 近戰 | 先清出退路，避免被牆角和大型怪物夾住；輸出後立刻重新定位。 |
| 弓箭或投射物 | 利用圈邊和長距離輸出，優先處理遠程怪與限制移動的敵人。 |
| 法術範圍流 | 把怪物拉到可重複覆蓋的區域，避免技能打在地形或障礙物上。 |
| 召喚流 | 讓召喚物承受第一波壓力，角色保持在退路附近，不要單獨追怪。 |
| 防禦型流派 | 可以承受較多正面傷害，但仍要注意持續地面效果與異常狀態。 |

## 七、常見失誤

### 還沒清怪就撿獎勵

物品名稱會遮住地面效果和敵人動作。先完成事件，再集中拾取。

### 在角落開祭祀

角落、窄門和橋面會限制閃避路線。啟動前先清出一塊能繞圈的空地。

### 為了打王怪站樁

大型怪物的生命值高，不代表要用生命換輸出時間。打出一輪技能後就移動，等下一個安全窗口再回頭輸出。

### 忽略地面傷害

祭祀中的怪物數量多，地面效果很容易被屍體、特效和地圖線遮住。角色停下來前，先確認腳下沒有持續傷害。

### 聊天或任務資訊遮住戰鬥畫面

需要閱讀聊天或任務內容時，先離開事件範圍或完成當前波次；戰鬥中保持畫面乾淨比即時回覆訊息更重要。

## 一、先記住三個原則

1. **先找完整祭祀區域，再決定啟動順序。** 不要只看到一座祭壇就立刻開打；先確認附近出口、狹窄地形與可能的回頭路。
2. **每次啟動都當成一個封閉戰鬥。** 先處理高威脅怪物與地面效果，再撿取掉落物，避免為了看獎勵被下一波攻擊打倒。
3. **獎勵要看角色當前需求。** 能直接提升生存或清圖效率的物品通常優先，暫時用不到的高價物品可以保留到後續再決定是否兌換或延後。

## 二、祭祀流程

### 1. 進圖後先做路線判讀

- 開啟地圖確認目前位置、已探索區域與尚未走過的岔路。
- 先清理祭壇周圍會妨礙走位的普通怪，保留足夠空間處理事件。
- 記下回城點、傳送點與最近的安全位置；死亡或需要整理背包時，能快速回到祭祀區域。
- 若祭祀位置靠近地圖邊緣、門口或狹窄通道，先把附近路線走通，再啟動祭壇。

### 2. 啟動祭壇前的準備

- 確認生命、能量護盾、魔力與藥劑已經回滿。
- 確認主要技能、光環、召喚物與防禦技能都已準備完成。
- 先處理會造成持續傷害、緩速、定身或封鎖走位的怪物。
- 遠程角色站在能看見祭壇又能退回安全區的位置；近戰角色不要把自己卡在牆角或祭壇邊緣。

### 3. 戰鬥中的處理順序

建議使用以下優先級：

1. 會快速接近或一次造成大量傷害的稀有怪、首領怪。
2. 會施放地面效果、投射物或範圍控制的怪物。
3. 會復活、強化其他怪物或持續召喚敵人的怪物。
4. 剩餘普通怪物與零散目標。

戰鬥時不要只盯著敵人血條。要不斷確認角色腳下、畫面邊緣與小地圖上的新怪物位置。當畫面變得混亂時，先移動到已清空的區域，再回頭輸出。

### 4. 戰鬥結束後再處理獎勵

- 先確認場上沒有殘留敵人或持續傷害。
- 依照角色需求檢查獎勵：生存裝備、關鍵技能資源、升級素材與高價值物品優先。
- 背包不足時，先記錄物品名稱與位置，再回城整理，不要在危險區域長時間停留。
- 若獎勵可延後處理，優先保留選項，等完成同一張圖的其他祭祀或確認市場價值後再決定。

## 三、截圖中的資訊怎麼看

### 地圖覆蓋層

截圖中可以看到地圖覆蓋在遊戲畫面上。它適合用來確認：

- 已走過與尚未探索的路線。
- 祭祀區域附近是否有可退的位置或另一條出口。
- 目前角色是否已離開主要戰鬥區，避免在未確認安全時直接打開背包或回城。

地圖覆蓋層不應取代實際畫面判斷。祭祀戰鬥時，仍要以地面效果、敵人動畫與角色血量為優先。

### 左側聊天欄

截圖中的聊天欄會遮住左下方視野。進入祭祀戰鬥前，建議縮小、關閉或移動聊天欄，避免遮住：

- 角色血量與護盾資訊。
- 地面效果與敵人接近方向。
- 地圖入口、掉落物或回撤路線。

聊天內容可作為隊伍溝通紀錄，但不要讓閱讀聊天取代戰鬥中的走位與血量判斷。

### 右側任務與區域資訊

右側資訊欄適合在安全時間確認目前區域、任務目標與尚未完成的事件。進入祭祀區域後，建議先完成戰鬥，再利用短暫安全時間檢查目標，不要在敵人仍存在時停下閱讀。

| 近戰 | 容易被包圍、地面效果限制走位 | 從外圍切入，先清一側，再沿已清空區域移動 |

| 脆皮高速清圖 | 清怪快但失誤成本高 | 不貪最後幾隻怪，血量下降或畫面失控就先撤退 |

## 五、常見失誤

### 還沒清路就啟動祭壇

祭祀戰鬥會限制注意力與走位。若入口、岔路或退路仍有大量怪物，事件開始後很容易被前後夾擊。先清出一條回撤路線，通常比多打幾隻普通怪更重要。

### 站在祭壇旁邊不動

祭壇是事件中心，不代表角色必須一直站在中心。可以在祭壇外圍繞圈，利用已清空的方向拉開距離，降低被範圍技能同時命中的機會。

### 為了撿東西停在危險區

掉落物可以等戰鬥結束後再撿。祭祀期間最重要的是維持生存與戰鬥空間；死亡後失去經驗、時間與路線進度，通常比漏撿一件普通物品更不划算。

### 聊天欄或地圖遮住關鍵畫面

截圖顯示聊天欄與地圖覆蓋層都可能佔用左下方視野。若角色正在處理祭祀，不建議同時開啟會遮擋戰鬥區域的介面；確認安全後再閱讀聊天或整理資訊。
