# POE1 3.29 閃現打擊暴徒拓荒與終盤整理

- 依 KingPinUwU 3.29 CotA 閃現打擊攻略整理：1～12 級用 Ground Slam（大地重擊）、13～37 級用 Sunder（裂地之擊）、38 級轉 Flicker Strike（閃現打擊）；後續依序為前期終盤、暴擊轉型。裝備詞綴、技能連線和昇華點按原作者配置整理；力量堆疊頁僅為示例，作者提醒不要照抄。

## 流派定位

| 項目 | 說明 |
|---|---|
| 遊戲版本 | PoE1 3.29 CotA；其他版本需重查技能、裝備與天賦 |
| 起始職業／昇華 | 野蠻人（Marauder）／暴徒（Berserker） |
| 玩法 | 閃現打擊（Flicker Strike）連續瞬移攻擊；躍擊（Leap Slam）與霜漣之瞬（Frostblink）移動 |
| 優點 | 原作者列出速度快、傷害好、操作簡單 |
| 缺點 | 原作者列出耐打度不足、位移方向不固定；打王時狂怒球有時無法穩定維持 |
| 進度版本 | 前期終盤 → 中後期暴擊轉型；力量堆疊只作示例，不建議照抄 |

> 原作者說明：戰役版本實際玩起來很強，但後期版本屬於一般閃現打擊配置，沒有特別機制；後期指引尚未完成更多細節。請把此篇視為有明確限制的 3.29 玩家配置整理，不當成已驗證的完整終盤畢業攻略。

## 配置階段

| 階段 | 變體 | 使用方式 | 重要提醒 |
|---|---|---|---|
| 1～12 級 | 大地重擊（Ground Slam） | 使用一般重擊拓荒；武器維持物理傷害 | 原作者 3.29 拓荒篇 |
| 13～37 級 | 裂地之擊（Sunder） | 13 級把大地重擊換成裂地之擊 | 先備好至少一件 3／4 連、含一個綠孔的防具，供 38 級轉型 |
| 38 級～Act 10 | 閃現打擊（Flicker Strike） | 取得多重打擊後轉型，需維持狂怒球 | 作者承認戰役拓荒經驗有限，首領戰狂怒球不一定穩定 |
| 前期終盤 | Early Endgame | 依原頁早期終盤變體 | 連線和裝備按原始 PoB |
| 中後期 | Mid~Late Endgame（暴擊轉型） | 原頁主要後期配置 | 使用下方六連與裝備詞綴表 |
| 力量堆疊 | Final Str Stacking | 原作者註明「僅為示例，暫勿照抄」 | 尚非推薦成品 |

## 技能連線表

技能名稱以繁中說明，括號保留英文原名。下列 1～38 級連線與後期六連分開列，避免把終盤技能串誤當成戰役配置。

| 階段／用途 | 技能連線 | 說明 |
|---|---|---|
| 1～12 級主攻 | 大地重擊（Ground Slam）＋殘虐輔助（Ruthless）＋機率流血輔助（Chance to Bleed） | 前期重擊配置；依插槽數逐步加入輔助 |
| 13～37 級主攻 | 裂地之擊（Sunder）＋殘虐輔助（Ruthless）＋機率流血輔助（Chance to Bleed） | 13 級替換大地重擊；之後可依作者建議把機率流血換成近戰物理傷害輔助 |
| 38 級轉型核心 | 閃現打擊（Flicker Strike）＋多重打擊輔助（Multistrike） | 作者以多重打擊與暴徒昇華維持狂怒球，首領戰仍可能偶爾斷球 |
| 38 級後其他主技能寶石 | 殘虐輔助（Ruthless）、機率流血輔助（Chance to Bleed）；作者後續建議可換近戰物理傷害輔助 | 原拓荒文未把每個連線位置固定成終盤六連，不自行指定串位 |
| 位移 | 躍擊（Leap Slam）＋快速攻擊輔助（Faster Attacks）＋動能輔助（Momentum）；另備霜漣之瞬（Frostblink） | 原拓荒寶石清單 |
| 戰役增益 | 血與沙（Blood and Sand）＋元素淨化（Purity of Elements）＋鮮血狂怒（Blood Rage） | 原拓荒寶石清單；盡量維持鮮血狂怒，留意生命消耗 |
| 中後期暴擊六連 | 閃現打擊（Flicker Strike）＋多重打擊輔助（Multistrike）＋殘虐輔助（Brutality）＋近戰物理傷害輔助（Melee Physical Damage）＋近身戰輔助（Close Combat）＋增加暴擊率輔助（Increased Critical Strikes） | 原頁 Mid~Late Endgame（Crit Swap）主連線 |
| 姿態／光環 | 血肉與岩石（Flesh and Stone）＋堅定（Determination）＋極地裝甲（Arctic Armour） | 原作者使用 Sand 姿態；血姿態偏傷害、沙姿態偏防禦 |
| 位移連線 | 躍擊（Leap Slam）＋快速攻擊輔助（Faster Attacks）＋動能輔助（Momentum） | 原頁後期配置 |
| 標記 | 刺客印記（Assassin's Mark）＋擊中時印記輔助（Mark On Hit） | 原頁後期配置；作者提醒提高刺客印記品質 |
| 防禦觸發 | 熔岩護盾（Molten Shell）＋受傷時施放輔助（Cast when Damage Taken） | 原頁後期配置；寶石等級見 PoB |
| 其他增益 | 鮮血狂怒（Blood Rage）＋自動化（Automation）；另有霜漣之瞬（Frostblink） | 原頁後期配置 |

中後期若把殘虐輔助換掉，原作者列出的替代品是增加暴擊傷害輔助（Increased Critical Damage）；這會影響傷害類型，先依 PoB 核對。

## 裝備要拿的能力

| 裝備 | 原作者指定能力／詞綴 | 原頁範例或替換說明 |
|---|---|---|
| 雙手斧 | 物理傷害、攻擊速度；有餘裕再找暴擊詞綴 | 作者要求全程使用物理傷害武器；可用磨刀石＋Rustic Sash（粗革腰帶）＋斧製作物理傷害，再於工藝台補攻速 |
| 項鍊 | 敏捷、命中 | 儘早戴 Jade Amulet（翠玉護身符）；作者指出它可補命中，且仍要滿足寶石／裝備的敏捷需求 |
| 其他戒指／項鍊／腰帶 | 元素抗性、最大生命、缺少的力量／敏捷／智慧 | 原作者明列先抗性、再生命、再護甲；Le Heup of All（全知之戒）或 Carnage Heart（屠戮之心）僅為預算示例，可換稀有裝 |
| 胸甲、頭盔、手套、鞋子 | 抗性、最大生命、護甲或護甲／閃避 | 原作者說防具不如武器重要，先確保插槽和抗性；鞋子另找移動速度 |
| 手套 | 抗性、最大生命、護甲／閃避 | 可選「非瓦爾打擊技能額外指定附近敵人」或威嚇詞綴；作者建議高密度刷圖可選額外目標 |
| 鞋子／珠寶 | 鞋子避免感電；搭配 Stormshroud（風暴籠罩） | 原作者列為後期元素異常免疫方案，非拓荒必需 |
| 珠寶 | 1% 物理攻擊傷害偷取魔力、免疫腐化之血；後期暴擊加成 | 作者提醒腐化之血免疫可減少依賴生命藥劑 |
| 藥劑 | 後綴依需求；暴擊時獲得藥劑充能的前綴 | 作者列出生命、花崗岩、獅吼、鑽石、紫晶藥劑作為配置示例 |
| 轉型插槽 | 至少一件三連或四連防具，且含一個綠孔 | 原作者要求在 38 級切閃打前先準備，避免拿到寶石卻無法連線 |

## 天賦方向

| 配置 | 原頁重點 | 用途／限制 |
|---|---|---|
| 1～37 級 | Versatility（多才多藝）優先，其次 Resolute Technique（必中）；斧專精選「斧擊命中獲得 2 點怒氣」 | 原作者列出的拓荒點法優先順序 |
| 38 級轉閃打 | Tribal Fury（部族之怒）為必要天賦；再拿「非瓦爾打擊技能額外指定 1 名附近敵人」專精 | 原作者明確說這是閃打轉型的必要點 |
| 暴徒昇華 | 先拿 Ancestral Fury（先祖之怒）維持狂怒球；Crave the Slaughter（渴求屠戮）也很有用 | 原作者表示先祖之怒對狂怒球續航是必要核心 |
| 中後期暴擊樹 | Iron Reflexes（霸體）；雙手武器、怒氣、暴擊、偷取、護體、斧、額外打擊、魔力保留、生命與物理專精 | 以原作者 3.29 Crit Swap 樹及 PoB 為準 |
| 力量堆疊 | 原作者特別註明只是示例、不要照抄 | 不列為推薦路線 |

原頁 Crit Swap 樹顯示 123 點主天賦與 8 點昇華天賦；這是 3.29 特定配置，不是角色轉型等級或通用天賦要求。閃現打擊靠狂怒球跳過冷卻，原作者 3.29 配置以多重打擊、先祖之怒與鮮血狂怒維持球數；他也提醒首領戰仍可能斷球。

## 操作與生存

| 情境 | 操作建議 | 風險提醒 |
|---|---|---|
| 清圖 | 主要連續施放 Flicker Strike；用 Leap Slam 或 Frostblink 趕路 | 角色會跳向目標，移動方向不完全由玩家控制 |
| 打王 | 先用 Leap Slam／Frostblink 調整位置，再施放 Flicker Strike；維持 Assassin's Mark | 隨機位移可能讓角色離開安全位置或撞進危險區域 |
| 防禦 | 確認生命、抗性、護甲與 Molten Shell 觸發設定，再提高內容難度 | 原作者把 Tankiness 列為弱點；不能只用高傷害補償防禦不足 |
| 物理傷害 | 升級武器並維持物理傷害配置 | 武器長時間不升級，傷害會明顯落後 |
| 異常狀態 | 先補足必要抗性；後期再評估避免感電與 Stormshroud 組合 | Stormshroud 是後期配裝方向，不是初期必備 |

## 轉型檢查

| 檢查項目 | 切換暴擊配置前確認 |
|---|---|
| 武器 | 使用物理傷害雙手斧；優先物理傷害與攻擊速度，再補暴擊 |
| 天賦 | 已點 Tribal Fury（部族之怒）與額外打擊專精；依暴擊變體更換天賦 |
| 寶石／插槽 | 38 級前備妥 3／4 連且有綠孔；取得閃現打擊與多重打擊後才轉型 |
| 屬性 | 敏捷足以穿裝備、升寶石；翠玉護身符用來補命中與敏捷 |
| 防禦 | 生命、抗性、護甲／閃避及藥劑能應付目前內容 |
| 操作 | 能接受閃現打擊的自動追擊與不易精準控制的位移 |
| 力量堆疊 | 暫不轉；原作者標示該頁僅是範例，尚未完成，勿依此配裝 |
| 地圖詞綴 | 避開怪物偷取狂怒／暴擊／耐力球的詞綴 | 原作者在留言中指出這類詞綴會讓流派無法運作 |
