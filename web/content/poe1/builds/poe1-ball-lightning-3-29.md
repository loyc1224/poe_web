- 路線：電球開荒 → 魔幻電球 → 能量之刃 → 力量之井，目標第一週穩定進入高階地圖，後期朝 T17、五玉與攻防兼顧發展。

> 路線：電球開荒 → 魔幻電球 → 能量之刃 → 力量之井

## 一、整體流程

## 五、雙持與格擋

| 項目 | 規劃 |
|------|------|
| 劇情期 | 雙持法杖，優先提高傷害與施法速度 |
| 雙持基礎格擋 | 提供少量攻擊格擋，增加基本容錯 |
| 右下雙持格擋圈 | 因路線會前往右下投射物速度區，可評估順路的高效率格擋點 |
| 雙持攻擊傷害詞綴 | 對電球無效，不要為了攻擊傷害繞路 |
| 是否追求 75/75 | 前期不追求，終盤再依裝備與天賦決定 |
| 防禦核心 | 生命／ES、抗性、護甲或閃避、格擋、移動與輸出共同組成 |

> 雙持相關天賦中的「攻擊傷害、攻擊速度」通常不會強化電球，只考慮格擋或其他確定對法術角色有效的部分。

## 十、魔幻切換檢查

符合以下條件再正式換成魔幻：

- 最大魔力至少約 1500，理想為 2000 以上。
- 技能消耗不會讓魔力瞬間乾掉。
- 有清晰、魔力回復或其他回魔手段。
- 換上魔幻後，實際打王傷害高於原本配置。
- 不因保留過多魔力而無法施法。

回魔不足時，先繼續使用：

```
電球
法術迴響輔助
穿透輔助
閃電穿透輔助
```

## 十二、核心原則

- Act 1 就直接使用電球，避免中途大幅改技能與天賦。
- 劇情到黃圖以前，先當作一般生命／魔力型電球角色。
- 前期不要提早穿半套 ES 裝，否則生命、抗性與傷害可能同時下降。
- 投射物速度對電球的清圖與手感非常重要。
- 雙持法杖先換取傷害與速度，格擋只拿順路且高效率的點。
- 黃圖開始收集轉型裝，但等整套足夠後再一次轉能量之刃。
- 每次換裝後重新檢查抗性、生命／ES、魔力、回復與實際傷害。

## 十六、終盤防禦層（T17 ／ 五玉）

### 防禦層架構

| 防禦層 | 目標數值 | 主要來源 |
|--------|---------|---------|
| 能量護盾 | 8000～12000+ | 象牙塔、ES 裝備、天賦 |
| 攻擊格擋 | 70～75% | 雙持天賦、格擋天賦節點 |
| 法術格擋 | 視配置而定 | Rumi's Concoction、法術格擋節點 |
| 元素抗性 | 全 75% | 裝備詞綴 |
| 混沌抗性 | 40～75% | 裝備詞綴 |
| ES 持續回復 | ~5%/秒+ | 判官神聖之地（Pious Path） |
| ES 偷取 | 擊殺時回 ES | 技能偷取詞綴或天賦 |

### 判官（Inquisitor）關鍵轉生天賦

| 天賦節點 | 效果 |
|---------|------|
| Pious Path | 踩在神聖之地上持續回復 ES |
| Righteous Providence | 力量與智慧各 +40，技能等級提升，ES 基礎大幅增加 |
| Inevitable Judgement | 暴擊擊中忽略敵人元素抗性，閃電穿透可換其他輔助 |
| Sanctuary | 神聖之地內減少承受傷害 |

### 能量之刃開啟後生存邏輯

1. 能量之刃啟用後 ES 保留 50%，需確保開啟前 ES **10000+**，轉型後至少 **5000+** 承傷。
2. 判官神聖之地持續回 ES，打王時快速補充。
3. ES 偷取在高密度怪群中提供近乎持續的 ES 補充。
4. 雙持格擋作為輔助層，減少吃到大傷的機率。
5. 王戰使用 **Rumi's Concoction** 強制提升格擋與法術格擋上限。
