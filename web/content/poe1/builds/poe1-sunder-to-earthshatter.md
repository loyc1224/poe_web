# POE1 3.29 裂地之擊拓荒轉大地震擊

- 依 Woolie 3.29 全昇華拓荒指南整理：角色等級 1～11 使用 Ground Slam（大地重擊），12 級取得 Sunder（裂地之擊）後一路拓荒，前期地圖仍用 Sunder，之後才轉 Earthshatter（大地震擊）Juggernaut（勇士）。技能串、裝備能力與轉型配置均按原作者頁面整理。

## 流派定位

| 項目 | 說明 |
|---|---|
| 遊戲版本 | PoE1 3.29 CotA；其他版本先核對技能、天賦與輔助寶石是否改動 |
| 戰役主技能 | 1～11 級 Ground Slam（大地重擊）；12 級於 Merveil's Caverns 取得 Sunder（裂地之擊）後替換 |
| 前期地圖 | 繼續用 Sunder；原作者明確將其列為 Earthshatter 轉型前配置 |
| 後期主技能 | Earthshatter（大地震擊），轉型目標為 Juggernaut（勇士） |
| 起始職業 | 原作者主要以 Marauder（野蠻人）示範，並表示 Duelist（決鬥者）或 Templar（聖堂武僧）也可跟拓荒流程 |
| 主要限制 | 傷害高度仰賴雙手武器；武器太久沒升級會明顯掉傷害 |

> 這份攻略是「Sunder 拓荒、Earthshatter 終盤」的轉型路線，不是從第一章就使用大地震擊。原作者的 3.29 攻略有逐章變體；本文整理核心決策，精確天賦點與每章寶石取得以原頁為準。

## 階段流程

| 階段 | 主技能與配置 | 推進重點 | 何時進下一階段 |
|---|---|---|---|
| 1～11 級 | Ground Slam（大地重擊） | 先連殘虐輔助（Ruthless）；完成海潮孤島任務後接機率流血輔助（Chance to Bleed） | 取得 Sunder 後替換主技能 |
| 12 級至 Act 10 | Sunder（裂地之擊） | 依原作者 Act 1～10 分頁逐章切換寶石、天賦與裝備；主技能先用機率流血、殘虐輔助 | 原頁逐章配置不同，不把某一章的整套串法套用全程 |
| 前期地圖 | Sunder（裂地之擊） | 勇士指南列出的前期串法為 Sunder、近戰物理傷害、殘虐、粉碎 | 保持 Sunder，直到裝備、天賦和連線能接上轉型配置 |
| 轉型後 | Earthshatter（大地震擊）勇士 | 改用下方主技能六連與戰吼配置；戰吼負責引爆地刺 | 依原作者 Earthshatter 終盤指南繼續調整 |

## 昇華選擇

原作者的戰役指南支援野蠻人三種昇華，並可由決鬥者或聖堂武僧跟跑；但他提供的 Earthshatter 終盤篇是勇士配置。作者表示勇士相較暴徒傷害較低、耐打度較高，並建議新手優先選勇士。這裡不自行推定酋長終盤配置。

| 昇華 | 方向 | 適合情況 |
|---|---|---|
| Juggernaut（勇士） | 原作者 Earthshatter 終盤攻略採用；強調防禦、回復與操作便利 | 新手可優先參考；終盤技能與天賦依勇士專頁 |
| Berserker（暴徒） | 原作者表示可沿用同一戰役拓荒指南；終盤傷害較高，但 Rite of Ruin 會帶來持續生命流失 | 想提高傷害時再評估，需另外確認終盤樹與生存 |
| Chieftain（酋長） | 原作者表示戰役指南適用；所給兩篇來源沒有酋長終盤配置 | 不把勇士終盤裝備或天賦直接套用 |

## 戰鬥操作

| 情境 | 操作順序 | 注意事項 |
|---|---|---|
| 清圖 | Leap Slam 或 Frostblink 越過怪群，再用 Sunder 攻擊追上來的怪 | 先拉出怪物行進方向，讓 Sunder 的範圍覆蓋更有效 |
| 打王 | Vulnerability → 有可用時施放 Intimidating Cry → 連續使用 Sunder | 詛咒需要時補放；戰吼可依原頁變體與可用魔力調整 |
| 回魔 | 拓荒期間常備並使用魔力藥劑 | 攻擊耗魔相對於魔力池可能偏高；可依原攻略保留較低階魔力藥劑 |
| Blood Rage | 進區域後確認是否需要施放，並留意持續掉血 | 依角色回復能力與當前危險度使用，不要在生存不足時盲目維持 |

技能與輔助名稱以繁中說明，括號保留原文供對照。戰役 Act 1～10 各有獨立變體；來源沒有提供可安全合併成單一逐章串法的文字，因此只列頁面明確寫出的連線，不補造其他章節。

| 階段／連線 | 技能串法 | 備註 |
|---|---|---|
| 1～11 級主技能 | 大地重擊（Ground Slam）＋殘虐輔助（Ruthless） | 擊殺 Hillock 後取得大地重擊 |
| Act 1 三連 | 大地重擊（Ground Slam）＋殘虐輔助（Ruthless）＋機率流血輔助（Chance to Bleed） | Mercy Mission 任務取得機率流血輔助；未有三連時依原作者指示暫時調整連線 |
| 12 級起主技能 | 裂地之擊（Sunder）＋機率流血輔助（Chance to Bleed）＋殘虐輔助（Ruthless） | 角色到 Merveil's Caverns 取得裂地之擊後，替換大地重擊 |
| 位移 | 躍擊（Leap Slam）＋快速攻擊輔助（Faster Attacks） | 角色等級 10 可使用躍擊；可用霜漣之瞬接躍擊落地動畫 |
| 姿態／增益 | 血與沙（Blood and Sand）；戰爭之旗（War Banner） | 原作者指定血姿態；戰爭之旗需要增傷時才開 |
| 戰吼／保命 | 威嚇戰吼（Intimidating Cry）；堅決戰吼（Enduring Cry） | 威嚇戰吼需要增傷時使用；堅決戰吼在生存吃緊時使用 |
| 移動技能 | 霜漣之瞬（Frostblink） | 原作者指定保持 1 級，不要升級 |
| 前期地圖主技能 | 裂地之擊（Sunder）＋近戰物理傷害輔助（Melee Physical Damage）＋殘虐輔助（Ruthless）＋粉碎輔助（Pulverise） | 依勇士指南的前期配置；實際連線數以裝備插槽為限 |
| Earthshatter 主技能六連 | 大地震擊（Earthshatter）＋近戰物理傷害輔助（Melee Physical Damage）＋過度施力輔助（Overexertion）＋戰爭之拳輔助（Fist of War）＋殘虐輔助（Brutality）＋粉碎輔助（Pulverise） | 原作者 Earthshatter Swap 主串 |
| 自動戰吼組 | 自動化戰吼（Autoexertion）＋威嚇戰吼（Intimidating Cry）＋煉獄戰吼（Infernal Cry）＋地震戰吼（Seismic Cry）＋戰法戰吼（Battlemage's Cry） | 原作者 Swap 組合；確認保留魔力，並錯開戰吼品質以調整冷卻 |
| 其他來源技能組 | 集結戰吼（Rallying Cry）＋緊急命令輔助（Urgent Orders）＋純淨捷（Herald of Purity）＋血與沙（Blood and Sand） | 原作者 Swap 配置 |
| 其他來源技能組 | 脆弱（Vulnerability）＋戰爭之旗（War Banner）＋鮮血狂怒（Blood Rage）＋活栓輔助（Lifetap） | 原作者 Swap 配置；鮮血狂怒留意生命消耗 |
| 位移技能組 | 霜漣之瞬（Frostblink）＋躍擊（Leap Slam）＋快速攻擊輔助（Faster Attacks）＋活栓輔助（Lifetap） | 原作者 Swap 配置 |

大地震擊的尖刺只能由戰吼引爆；每次攻擊應確保至少一個戰吼觸發。打王順序依原作者為脆弱與戰爭之旗（可用時）、集結戰吼、大地震擊連打 2～3 次，再重複戰吼與攻擊。

## 裝備要拿的能力

原作者明確指出武器是最重要的裝備，其餘裝備不必追固定底材，先看詞綴數值。下表只整理來源明列的優先級。

| 裝備 | 優先取得的能力／詞綴 | 原作者建議 |
|---|---|---|
| 雙手斧 | 增加物理傷害 | 每章依角色等級換當下可取得的斧底材；武器傷害不足時優先處理 |
| 雙手斧製作 | Rustic Sash（粗革腰帶）＋磨刀石＋任意雙手斧 | 商人配方產生增加物理傷害詞綴；魔法或稀有腰帶可提高詞綴數值，但稀有度也會提高裝備需求等級 |
| 頭盔、胸甲、手套、鞋子 | 最大生命、元素抗性 | 原作者將生命與抗性列為一般裝備主要需求 |
| 防具底材 | 護甲或護甲／閃避混合底材 | 原作者指出這些底材更容易出現所需顏色的插槽 |
| 戒指、項鍊、腰帶 | 最大生命、元素抗性 | 不要求特定底材；以現有物品詞綴為主 |
| 空詞綴欄 | 生命或抗性等當前缺口 | 使用工藝台補上可用的空詞綴 |
| 藥劑 | 生命、魔力、移動速度及護甲用途 | 原配置展示生命藥劑、魔力藥劑、跑速／銀器、花崗岩與玄岩藥劑；攻擊期間常補魔 |

## 轉型檢查表

| 檢查項目 | 達成條件 | 未達成時 |
|---|---|---|
| 版本 | 原頁或 Path of Building 已切到目前遊戲版本 | 先核對技能、輔助寶石與天賦專精，不照搬 3.29 數值 |
| 武器 | 有足以支撐地圖的雙手物理武器 | 先升級武器，再評估更換主技能 |
| 寶石連線 | 能配置 Earthshatter Swap 的主技能連線 | 暫時繼續 Sunder，不為了轉型犧牲過多傷害 |
| 天賦 | 可按原頁轉型樹調整，並預留所需重置點 | 先完成必要任務天賦點與重置準備 |
| 防禦 | 生命、抗性和護甲配置足以應付目前地圖 | 補裝與抗性後再提高地圖難度 |
| 操作 | 明白戰吼如何配合 Earthshatter 與自動施放設定 | 先確認 Autoexertion 保留魔力和戰吼觸發節奏 |

轉型後請到 Earthshatter 專頁核對完整裝備與後期技能。若主技能傷害、回復或生存明顯下降，先回到 Sunder 配置修正裝備和天賦，不必勉強一次轉完。

## 優缺點

| 優點 | 代價／限制 |
|---|---|
| Sunder 起步早、範圍大，適合近戰拓荒 | 傷害仰賴武器，升級節奏不能停 |
| 每章有獨立變體，戰役流程清晰 | 戰吼、保留魔力與主技能連線需要管理 |
| 可在前期地圖繼續使用 Sunder，準備後再轉型 | Earthshatter 不宜只換寶石，天賦、裝備與操作也要一起核對 |
| 後期可接 Earthshatter Juggernaut 指南 | 原資料為 3.29；新版本必須重新核對數值與配置 |
