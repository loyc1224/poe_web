# 裂痕 + 譫望 策略（高擊殺／疊層）

## 策略核心
- 核心目標：利用**高擊殺速度**去推高譫望層數，並搭配裂痕、超越與藍王怪群，讓整張地圖的怪量與獎勵一起拉高。
- 這套的本質不是只看單一機制，而是用**裂痕開怪量、譫望吃層數、超越補通貨與密度**，把整張圖變成高密度收益圖。
- 與裂痕 + 花園相比，這套更偏向**高波動但上限更高**，而且更吃角色清怪速度與生存能力。

## 基礎收入結構
- **固定收入**：譫望玉（依種類與市場價格波動）。
- **穩定收益**：卡片譫望玉約 **70C**，也可以留著自用。
- **變動收入**：裂痕怪掉落、超越怪通貨、譫望獎勵層數拉高後的額外掉落。
- **額外收入**：高密度地圖帶來的通貨、卡片、碎片與額外機制掉落。

## 與圖天賦點法（優先順序）
1. 先補藍王怪群（魔法怪群）與怪群量，穩定提高整體擊殺密度。
2. 裂痕圈優先，讓地圖內固定有大量怪群可供譫望疊層。
3. 超越圈補上，利用高擊殺把超越觸發率與怪量再往上堆。
4. 譫望圈以**玉與層數**相關天賦為主，其他非核心節點可視點數取捨。
5. 若點數不足，先保留「裂痕＋藍王怪群＋譫望玉／層數」，再補超越外圈。

## 與圖天賦實際點法（依你的截圖）
- 這張樹的主體是**上方起手，往左右外圈擴張**，核心思路很明確：
  - 上方先接出**藍王怪群／怪群量**
  - 左側接**裂痕**
  - 右側接**譫望**
  - 中間與側邊穿插補**超越**
- 你的這版不是全點滿譫望，而是偏向**只拿玉與層數效率**，把多餘點數留給裂痕與怪群量，這樣比較符合高擊殺打法。

## 捷圖（譫望版本）

- 這張與圖是**裂痕主體 + 譫望核心 + 超越補量**的配置。
- 從路線來看，重點不是把譫望整圈全部塞滿，而是：
  - 保留**譫望玉**相關收益
  - 補**譫望層數／獎勵成長**
  - 再把點數優先投資到裂痕與怪群量
- 這種點法比較符合你目前這套「高擊殺、高密度、靠裂痕撐譫望層數」的打法。

### 譫望區域的點法重點
1. **優先拿玉**
   - 因為譫望玉本身就是穩定收入來源。
   - 玉價格落差大，所以先把最直接影響收益的點拿起來。

2. **再拿層數／獎勵成長**
   - 這會直接影響你每張地圖最後拿到的譫望獎勵品質。
   - 如果角色清圖速度夠快，這些點的回報會非常明顯。

3. **非核心譫望小點可延後**
   - 如果要在裂痕、超越、怪群量之間做取捨，通常譫望的邊角小點不是最優先。
   - 先保留核心收益，再看剩餘點數補不補滿。

### 為什麼不是全壓譫望
- 因為你的這套收益來源不是只靠譫望。
- 真正的結構是：
  - **裂痕**提供大量怪群
  - **藍王怪群**提高底層密度
  - **超越**放大整張圖收益
  - **譫望**把高密度轉化成更高獎勵
- 所以譫望在這裡更像是**收益放大機制**，不是唯一主體。

### 建議點法順序
1. **先從上方起手，補藍王怪群與怪群量**
   - 這是整張圖的底層收益來源。
   - 因為裂痕與譫望都很吃基礎怪量，所以先把魔法怪群相關點出來，整體手感會最穩。

2. **左邊先接裂痕主圈**
   - 裂痕是這套的主要開怪手段。
   - 先把裂痕的出現、裂痕手感、裂痕怪量補齊，這樣每張圖都有足夠密度給譫望疊層。
   - 如果點數有限，裂痕圈的優先度會高於譫望的非核心小點。

3. **右邊再接譫望主圈，但只拿核心節點**
   - 你的思路比較像是：
     - 拿**譫望玉**
     - 拿**譫望層數／獎勵成長**
     - 其他太分散或性價比普通的點可先略過
   - 這樣能把點數集中在真正有收益的節點上，不會為了補滿譫望而犧牲裂痕或超越。

4. **中段與外圈補超越**
   - 超越在這套是收益放大器，不是主體，但非常重要。
   - 因為你本身就有高密度怪群，超越能自然補出更多怪與通貨收益。
   - 所以建議在裂痕與譫望骨架成形後，把超越核心路線補起來。

5. **最後補剩餘的藍王怪群與效率小點**
   - 如果主體已經成形，剩下的點數可補：
     - 藍王怪群
     - 怪群量
     - 路線上順手經過的效率點
   - 這些點不一定最亮眼，但會讓整體地圖收益更穩。

## 簡化成一句話的點法
- **先怪群量，再裂痕，後譫望核心，最後補超越。**

## 如果點數不夠，建議取捨
- **必拿**：藍王怪群、裂痕主圈、譫望玉／層數核心。
- **次拿**：超越主圈。
- **可延後**：譫望非核心小點、外圍較遠的補充節點。

## 這張樹的打法定位
- 這不是純譫望專精樹，而是**裂痕主體 + 譫望增益 + 超越放大**。
- 好處是：
  - 地圖整體怪量夠高
  - 譫望層數更容易往上堆
  - 不會因為全壓譫望而讓其他收益斷掉
- 缺點是：
  - 吃角色清圖速度
  - 若機體不夠，譫望收益會不如預期

## 實戰操作補充
- 開圖後不要停，優先往怪群多的方向推進。
- 裂痕看到就完整跟完，因為這是撐譫望層數最重要的來源之一。
- 如果當張圖打起來壓力太大，優先保留「裂痕 + 怪群量」，譫望可以先降一階測試。

## 實戰重點
- 開圖後要維持一路推進，不要停太久，避免譫望效率下降。
- 裂痕是主要怪量來源，遇到裂痕要完整吃滿，讓譫望層數更穩定往上堆。
- 超越適合配合高密度清圖節奏一起吃，越能連續清掉怪群，收益越高。
- 這套比裂痕 + 花園更吃角色強度，尤其是：
  - 清圖速度
  - 範圍傷害
  - 生存能力
  - 長時間高密度戰鬥穩定性

## 譫望玉收益觀念
- 一般譫望玉價格約 **30C ~ 70C**。
- **卡片玉**價格約 **70C**，若市場價格不差，可直接當穩定收入；若你自己要打卡片，也能保留自用。
- 譫望玩法的關鍵不是只看單顆玉價格，而是看：
  - 每張圖能堆到幾層
  - 是否能穩定打完整張
  - 是否能把裂痕與超越都吃滿

## 進階變化打法
- 另一個變化是走**卡片譫望玉 3 顆，總計 60% 瘋狂值**。
- 這樣做的核心概念是：
  - 保證一層就有 **3 個卡片獎勵包**
  - 若整體流程能穩定打到約 **14 ~ 16 層**，收益會相當穩定
- 以你的描述來看，這條線屬於**難度較高，但收益更固定**的版本。
- 粗略觀念可整理成：
  - **3 包 × 14~16 層**
  - 屬於偏固定收益打法
  - 你估算大約可落在 **70 個約 1D** 的級距

## 這套的優點
- 比純花園更有爆發空間。
- 地圖整體怪量高，打起來手感好。
- 譫望玉本身就能形成一條穩定收入線。
- 若角色夠強，裂痕、譫望、超越三者疊起來的收益上限很高。

## 這套的缺點
- 比裂痕 + 花園更危險。
- 對角色機體要求更高。
- 若清怪速度不夠，譫望層數與收益會明顯下滑。
- 若地圖停頓太多，整張圖效率會被拉低。

## 建議補充
- 這套很適合搭配**開闊、好跑圖、不卡地形**的地圖，能更穩定維持譫望節奏。
- 若你的角色目前只能穩定打「裂痕 + 花園」，那譫望版建議先從低成本測試，再慢慢升級成高層數版本。
- 市價波動大時，可以把譫望玉分成：
  - 直接賣
  - 自用打高價值組合
  - 留高價玉、賣低價玉
- 若要走 3 顆卡片玉版本，建議先確認：
  - 你的清圖速度是否能穩定維持
  - 你的角色能否承受更高地圖壓力
  - 你的投入成本是否能被穩定回收

## 簡版結論
- **裂痕 + 譫望** 是偏高上限、高密度、高要求的打法。
- 核心思路就是：**高擊殺 → 高層數 → 高獎勵**。
- 若角色夠強，這套通常比保底型策略更有天花板。
- 若角色還沒成形，先打裂痕 + 花園會更穩，等機體完成再轉裂痕 + 譫望會更舒服。
